# Courbes

Une **courbe** décrit comment un mouvement se déroule dans le temps. Le même glissement de gauche à droite peut démarrer doucement puis accélérer, arriver en freinant, ou rebondir à la fin. Cette sensation se règle avec l'**accélération** (easing).

## Choisir une accélération

Partout où une animation ou une transition a un réglage **Easing**, choisissez une courbe toute faite dans la liste (linéaire, entrée douce, sortie douce, entrée-sortie douce, et d'autres). Linéaire avance à vitesse constante, ce qui paraît souvent mécanique ; entrée-sortie douce est naturelle pour la plupart des mouvements.

## Courbes personnalisées

Choisissez **Courbe personnalisée (Bézier)** pour dessiner la vôtre. L'éditeur de courbes affiche un graphique : le temps en bas, la progression sur le côté. Faites glisser les deux poignées pour former la courbe. Une partie raide de la courbe est rapide, une partie plate est lente. Vous pouvez prévisualiser le mouvement pendant que vous ajustez.

## Conseils

- Gardez la même accélération pour des mouvements similaires afin que le jeu paraisse cohérent.
- De courtes durées (un quart à une demi-seconde) avec une sortie douce donnent une impression de réactivité aux éléments d'interface.
